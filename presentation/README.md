# lets-play API — Site de Soutenance

## Lancement

Ouvrir `presentation/index.html` dans un navigateur.

> Aucun serveur requis — fonctionne en local (file://).

## Structure

```
presentation/
├── index.html        ← Page principale (toutes les sections)
├── style.css         ← Styles premium dark mode
├── script.js         ← Animations et interactions
├── assets/           ← Logos, captures, icônes (à ajouter)
└── sections/         ← Composants HTML séparés (optionnel)
```
